# Flask-Breadcrumbs-2

Modernized version of
[Flask-Breadcrumbs](https://github.com/inveniosoftware/flask-breadcrumbs),
originally created by [Invenio Software](https://github.com/inveniosoftware).

This is a drop-in replacement created to support Flask-Menu 2 and Flask 3.
For README and docs, please see the original repository.

I do not recommend using this library - I do not think I will be supporting it
and keeping it up to date. Only use it if you have too much legacy code.

Installation is as easy as `pip install flask-breadcrumbs-2`.
